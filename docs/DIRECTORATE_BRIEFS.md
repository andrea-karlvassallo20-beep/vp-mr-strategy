## Family A — pre-registration hardening (hardening rule 1; the
sign-kill-line template's family)

These five generalize the same lesson: whatever is chosen after seeing
the data can manufacture the find. Each one pre-declares, before the
data, a piece of the test that would otherwise be a researcher degree
of freedom.

- **A1. The C1-L2 base-rate confrontation** (31st, queued 2026-11-19,
  log ## 65, note `paper/research/misses_curriculum_c1l2_confrontation_2026-11-19.md`).
  Before the L0 gate passes, the C1-L2 test spec must carry a
  pre-declared base-rate confrontation section: the frozen 2026-11-16
  daily-grain priming table quoted whole (873 series, 1,765,316
  series-days, coverage 0.039, P(move|primed) 0.01668, P(move|not
  primed) 0.00807, lift 2.07), a pre-declared novelty statement of
  what an L2 positive must add beyond the daily grain, a pre-declared
  horizon bridge between the spec's wall-clock barriers and the daily
  10-bar horizon, and the daily lift printed beside any reported L2
  effect size. Closes the channel where a daily-grain re-discovery
  could be sold as a book-resolution find.
- **A2. The self-excitation regime-window pre-declaration** (32nd,
  queued 2026-11-19, log ## 67, note
  `paper/research/library/2026-11-19_self_exciting_negative_resilience_deep_read.md`).
  Any spec proposing to identify a self-excitation or
  negative-resilience regime must carry a pre-declared regime-window
  rule (boundaries from frozen constants, no post-data adjustment) and
  a pre-declared proximity treatment stating the distance from
  candidate windows to the terminal horizon, because the
  Ackermann-Kruse-Urusov paper shows the same magnitude produces a
  qualitative effect or none depending only on where the window sits.
- **A3. The primary-metric pre-commitment** (33rd, queued 2026-11-19,
  log ## 69, note
  `paper/research/library/2026-11-19_duration_flexresidual_self_exciting_deep_read.md`).
  Any C1-L2/C8-adjacent test spec must pre-declare its single primary
  evaluation metric or loss, named and frozen before the data;
  secondary metrics may be reported but can neither rescue a primary
  failure nor overturn a primary pass. The Lee flexible-residual
  duration paper shows the metric choice alone reverses the forecast
  verdict at 1% significance on the same data.
- **A4. The flash-crash named event window** (7th in join order, one of
  the session-6 pair, queued 2026-11-16, log ## 10, note
  `paper/research/library/2026-11-16_crypto_micro_shap_deep_read.md`).
  The October 10, 2025 flash crash sits INSIDE the 2025-26 test year;
  pre-declare it in the split manifest as a named event window,
  reported separately from the pooled reading, so a single
  well-timed short cannot masquerade as a general hazard effect (the
  concrete instance of K4). The date must be verified against the
  venue feed at the L0 gate, not trusted from the paper.

- **A5. The level-versus-memory disambiguation for self-excitation
  claims** (35th, queued via deep-read 59, log ## 74, note
  `paper/research/library/2026-11-20_buffer_hawkes_process_lob_deep_read.md`).
  Before the L0 gate, any count-based self-excitation claim must carry
  a pre-declared concurrent book-depth control arm separating the
  level effect (book size mechanically scaling the rate) from the
  memory effect, both directions reported before the data; the
  Kaj-Caglar buffer-Hawkes paper proves a model whose
  market-order intensity is a function of the instantaneous book size
  alone, carrying no temporal kernel on the execution count, still
  produces Hawkes-identical clustering with Borel-distributed cluster
  progeny and inflated dispersion, while the (intensity, count)
  marginal is provably non-Markovian with the book size the hidden
  confounder — counts alone cannot distinguish level from memory.

## Family B — estimator discipline on the branching-ratio read

The trigger's number must be earned by the fit, not by the optimizer's
convenience. The founding items tighten how a branching-ratio estimate
may be read; the later ones extend the same discipline to every
estimator, preprocessing stage, inversion and transform a C1-L2/C8-adjacent
computation will touch. These sixteen are the read-out and
earned-number discipline of the programme.

- **B1. The K7 estimation pre-declaration cluster** (3rd, session 4,
  counted as one sharpening, log ## 8, note
  `paper/research/library/2026-11-16_hawkes_branching_deep_read.md`).
  Pre-declare the estimation window W, the timestamp-precision
  handling, and that the 0.8 branching threshold binds at the frozen
  W; report the model-independent mean-variance cross-estimator
  n-hat = 1 − sqrt(mu_W/sigma_W) beside the fit.
- **B2. The W-ladder report** (4th, session 4b, log ## 8, same note
  as B1's session lineage). Pre-declare a small ladder (e.g.
  10s/30s/5min) and report n-hat at all three together, because the
  source paper's own Fig. 5 shows 1 − n-hat scaling with W.
- **B3. Amendment-1** (5th, session 4b, log ## 8). The companion
  amendment text paired with the W-ladder in the 4b record; full text
  in the log entry's record.
- **B4. The boundary-solution rule** (9th, queued 2026-11-16, log
  ## 11, note
  `paper/research/library/2026-11-16_price_discovery_herding_deep_read.md`).
  A branching-ratio point estimate may be the optimizer hitting the
  wall of the stability constraint: the source's own estimate 0.998
  carried a bootstrap CI of [0.050, 0.660] with the appendix naming
  the cause. A boundary solution aborts the reading rather than
  counting as criticality.
- **B5. The optimizer-path (multi-start) disclosure rule** (28th,
  queued via deep-read 43, log ## 51, note
  `paper/research/library/2026-11-19_apparent_criticality_calibration_hawkes_deep_read.md`).
  Any multi-extrema likelihood (the three-parameter exponential-fit
  family included) must disclose the optimizer path and use
  multi-start, because a suboptimal minimum can sit in the
  supercritical regime and look like criticality.
- **B6. The ACF-shape kernel-validity gate** (14th, queued 2026-11-18,
  log ## 18, note
  `paper/research/library/2026-11-18_carma_hawkes_intensity_deep_read.md`).
  Before a branching-ratio trigger reading, the fitted kernel's
  implied ACF shape must pass a validity check — a misfit shape can
  mask criticality and mis-anchor the trigger.

- **B7. The estimator-configuration freeze** (37th, queued via
  deep-read 63, log ## 81, note
  `paper/research/library/2026-11-20_neural_hawkes_fabre_muni_toke_deep_read.md`).
  Any C1-L2/C8-adjacent kernel- or other estimator-dependent
  computation pre-registers, before fitting, its FULL estimator
  configuration (the second-order-statistics grid, the truncation
  horizon, the sampling scheme, any loss or magnitude weightings, the
  quadrature counts and the training configuration), chosen from a
  declared generic default with every deviation a dated amendment
  BEFORE the data is touched; the Fabre–Muni Toke neural Hawkes paper
  proves the same characterization equation on the same
  second-order statistics yields kernel shapes that swing with
  exactly these choices — the Wiener-Hopf benchmark on a poorly
  chosen grid "can still generate kernels with oscillatory behaviours
  which could lead to false discoveries in practical cases" (PDF
  p. 21) — and the paper's own remedy is a frozen generic
  configuration with no fine tuning.
- **B8. The price-process-family invariance rule** (38th, queued via
  deep-read 66, log ## 85, note
  `paper/research/library/2026-11-20_stochastic_price_dynamics_lob_deep_read.md`).
  Any book-defined statistic that prices time through an assumed
  price process pre-declares, BEFORE the data, the price-process
  family entering its definition, from a declared generic default,
  with the killed-if-wrong counterfactual recorded; the
  Langnau–Punchev paper proves the same reconstructed book yields an
  impatience rate that is an explicit function of the distance-to-
  fill AND the estimated volatility under geometric Brownian motion
  (day-level dispersion exploding to 43-88, an implied-volatility
  smile rising with distance-to-fill) and a level-independent rate
  with collapsed dispersion and no smile under Kou — the family
  alone, an analyst property, sets whether the statistic means
  anything.

- **B9. The adaptive-retraining disclosure** (40th, joined via
  deep-read 75, log ## 96, note
  `paper/research/library/2026-11-21_cryptocurrency_deep_learning_price_formation_deep_read.md`).
  Before the L0 gate, any C1-L2/C8-adjacent comparator, null or
  baseline that adapts — retrains, re-tunes, re-estimates or
  re-selects — inside its own evaluation window must pre-declare the
  adaptation rule (trigger, data consumed, cadence) in the same
  pre-registration as its frozen configuration and report the
  frozen-configuration number side-by-side; a number that exists only
  after its model has consumed the evaluation data may not enter any
  spec as support. The Fang–Chung–Ventre–Basios cryptocurrency
  deep-learning paper proves the mechanism is real: the universal
  LSTM decays to almost random guessing on live data (Fig. 9, PDF
  pp. 14-15), the headline 78% live accuracy exists only under
  walkthrough retraining that consumes the live data every 196
  predictions (PDF p. 17), the static multi-label model falls below
  40% against a 25% floor (PDF p. 19), and the retrain trigger itself
  is analyst-tuned ("Modified MDD" over 15%, PDF p. 9). Recorded for
  the sitting (## 97): two independent full reads of the same paper
  graded this mechanism differently — once an interpretation
  caution, once the sharpening — and the corrigendum judges the
  extension genuinely additive on the refutation-instrument axis (an
  adapted-in-window null tracks any regime change by construction and
  could never refute anything); PENDING OWNER RATIFICATION either way.

- **B10. The noise-model pre-declaration for de-noised inputs** (41st,
  queued via deep-read 76, log ## 100, note
  `paper/research/library/2026-11-21_parametric_mmn_plugin_deep_read.md`).
  Before the L0 gate, any computation, comparator, null or baseline
  that feeds a de-noised, reconstructed or "efficient"-price input
  must pre-declare the noise functional form AND the exact
  limit-order-book variable set entering it, counted in the
  multiplicity ledger; a number that survives only under a post-hoc
  swap of the noise model may not enter any spec as support. The
  Clinet–Potiron parametric-noise paper's own recount moves the
  residual-noise share from ~0% to 20-30% of noise variance with
  nothing changed but the choice of the functional form — the
  de-noising form is a silent dial that can scrub inconvenient
  structure into the "noise" term. Extends the estimator-configuration
  freeze (B7) from the estimator's fitting configuration to the
  preprocessing stage that defines its input.
- **B11. The feature-normalization pre-declaration** (44th, queued via
  deep-read 83, log ## 110, note
  `paper/research/library/2026-11-21_optimal_execution_reinforcement_learning_deep_read.md`).
  Any signal defined through a rolling or windowed normalization (a
  min-max rescaling, a z-score, a rolling-mean subtraction, a rolling
  volatility scale) must pre-declare, in the same frozen signal
  definition, the window length, the estimation convention (strictly
  trailing, excluding the evaluation point) and the warm-up handling;
  a number that survives only under a post-hoc normalization window
  fails by rule. The Zheng–He–Yang cross-exchange paper's signals rest
  on rolling normalizations whose windows are never stated — unauditable
  from the text, which is itself the reason the rule must bind before
  the data.
- **B12. The estimator-implementation concordance rule** (46th, queued
  via deep-read 85, log ## 113, note
  `paper/research/library/2026-11-22_market_impact_ofi_conditional_deep_read.md`).
  Every registered descriptive statistic, admission null, comparator
  or refutation instrument whose estimator is defined in writing must
  carry a one-time concordance audit of the executable implementation
  against the written definition — for silent numeric transformations
  the text does not declare (clips, floors, winsorization, dropped
  observations, same-timestamp aggregation); a number produced by an
  implementation that does not match its written definition is
  inadmissible at the gate. The Bugaenko paper's own Eq. 20 defines a
  signed mean while its Algorithm 1 clips every negative signed
  response to zero — the headline positivity partially manufactured by
  the transformation.
- **B13. The model-inversion identifiability pre-declaration** (49th,
  queued via deep-read 91, log ## 120, note
  `paper/research/library/2026-11-22_multivariate_hawkes_lob_option_pricing_deep_read.md`).
  Any computation that inverts a parametric model onto an observed
  quantity (implied volatility onto order-flow moments, a measured
  score onto a latent intensity) must pre-declare which parameters are
  FROZEN and from where, an identifiability statement proving the
  observed quantity admits a unique parameter split, and an
  input-provenance trace proving the "observed" input is not itself
  generated by the model family being inverted. The Guo–Swishchuk–
  Rémillard option-pricing paper's implied order-flow construction
  splits one observed scalar between two unknowns through an
  analyst-supplied constant — the "forecast information" created by
  the split, not measured.
- **B14. The transform-domain admissibility pre-declaration** (50th,
  queued via deep-read 92, log ## 121, note
  `paper/research/library/2026-11-22_vix_options_heston_hawkes_deep_read.md`).
  Any statistic computed through a transform of the data or of a
  fitted model (a characteristic-function or Fourier-inversion
  estimator, an affine pricing formula, a spectral representation)
  must pre-declare the domain of existence of the transform as a
  function of the frozen parameters, a recorded check that every
  evaluation point lies inside it, and the numerical-tolerance
  convention for truncation; an evaluation outside the proven domain
  is UNDEFINED by rule, and an implementation that silently returns a
  finite number fails the concordance audit (B12).
- **B15. The moment-equivalence disclosure** (51st, queued via
  deep-read 93, log ## 122, note
  `paper/research/library/2026-11-22_transform_analysis_hawkes_dark_pool_deep_read.md`).
  Any comparator, null or statistic built from a marked point-process
  or marked-intensity construction must pre-declare which of its
  outputs are moment-bounded (functions of finitely many moments of
  the mark law, hence inheritable from a moment-matched calibration)
  and which are law-sensitive; a concordance or validation audit that
  matches only finitely many moments may certify only the
  moment-bounded outputs. The Gao–Zhou–Zhu dark-pool transform theory
  proves in print that the mean fill outputs depend on the mark law
  only through its first moment while same-mean mark laws produce
  systematically different fill-rate outputs.
- **B16. The strategy-class/convention well-posedness pre-declaration**
  (52nd, queued via deep-read 102, log ## 134, note
  `paper/research/library/2026-11-23_cadlag_semimartingale_optimal_execution_deep_read.md`).
  Any comparator, null, cost model, simulator or refutation instrument
  that defines a cost, objective or "optimality" statement must
  pre-declare the admissible process/strategy class over which the
  definition is posed and a recorded well-posedness statement for the
  pairing of that class with the chosen bookkeeping convention
  (boundedness-below over the declared class, or the dated limiting
  derivation that produced the convention). The Ackermann–Kruse–Urusov
  execution paper proves twice in print that conventional finite-
  variation bookkeeping becomes catastrophically ill-posed
  (infimum −∞, constant positive parameters) the moment the strategy
  class widens — the divergence living only in the infimum so no
  computed value shows it. Extends the concordance rule (B12) from the
  implementation-vs-definition half to the class pairing.

## Family C — branching-ratio trigger robustness arms

What else could read as reflexivity even without self-excitation.
These five pre-build the nulls and disclosures that keep the trigger
honest.

- **C1. The per-branch rule** (10th, queued 2026-11-16, log ## 13,
  note
  `paper/research/library/2026-11-16_symmetric_hawkes_diffusion_deep_read.md`).
  The branching matrix Q is read per branch (self q_s vs cross q_c)
  with bootstrap CIs; ONLY q_s can carry the cascade interpretation —
  q_c is the mechanical mean-reversion branch.
- **C2. The near-critical regime-disclosure rule** (17th, queued
  2026-11-18, log ## 23, note
  `paper/research/library/2026-11-18_functional_limit_theorems_deep_read.md`).
  Every exponential-family kernel gives weak criticality only
  (long-run behavior fixed by the offspring mean and the dispersion),
  where the rescaled intensity converges to a CIR process WITHOUT mean
  reversion; any near-critical reading must disclose the regime.
- **C3. The deterministic-clock null arm** (19th, queued via deep-read
  19, log ## 26, note
  `paper/research/library/2026-11-18_sparse_orderbook_electricity_deep_read.md`).
  The trigger's null family must include a deterministic-clock null:
  simulated books with strong clustering and ZERO self-excitation,
  all generated by calendar-time intensities, still match empirical
  spread distributions. A book that clocks, not excites, must be
  constructible before the trigger earns its name.
- **C4. The latent-common-cause robustness arm** (20th, queued via
  deep-read 20, log ## 27, note
  `paper/research/library/2026-11-18_hawkes_otc_market_making_deep_read.md`).
  Correlated reactions to a common unobserved cause, if omitted from
  the baseline, are absorbed into the excitation kernel and produce a
  large branching ratio; the arm pre-declares the discriminating
  comparison against latent-factor/Cox specifications.
- **C5. The release-calendar lead component** (21st, queued via
  deep-read 22, log ## 30, note
  `paper/research/library/2026-11-18_returns_ofi_macro_news_deep_read.md`).
  The deterministic-clock null's release handling must begin BEFORE
  the release stamp with a declared pre-release lead (the source's
  shifts begin at ANN_t-1), or the null misses the window that
  matters.

## Family D — admission-null design for short-horizon flow features

- **D1. The two-null admission rule** (13th, queued 2026-11-18, log
  ## 17, note
  `paper/research/library/2026-11-18_queue_imbalance_deep_read.md`).
  Any C1-L2/C8 short-horizon flow feature is admitted only if it adds
  value beyond BOTH the constant-1/2 null the literature grades
  against AND the two-line state-variable null (a pure depth
  snapshot), which already achieves out-of-sample AUC 0.75-0.81
  large-tick one mid-change ahead with in-sample ≈ out-of-sample.
- **D2. The size-state persistence comparator** (16th, queued via
  deep-read 14, log ## 20, note
  `paper/research/library/2026-11-18_general_compound_hawkes_lob_deep_read.md`).
  A third admission null built from nothing but the tape: the
  size-state term (a quantile Markov chain on mid-move sizes)
  recovers 28-60% of the mean residual the intensity-only fixed-tick
  model missed on the multi-tick names.

- **D3. The sign-persistence admission null** (36th, queued via
  deep-read 60, log ## 77, note
  `paper/research/library/2026-11-20_cox_ratio_order_flows_deep_read.md`).
  Any short-horizon sign or aggressive-flow feature is admitted only
  if it adds value beyond a PRE-REGISTERED sign-persistence null
  (the last-sign repeat, zero parameters), with the survival shown
  in the sign-CHANGE subsample: the Muni Toke–Yoshida paper proves
  the zero-parameter repeat rule correctly signs more than 80% of
  ~54 million trades across 36 Paris Stock Exchange stocks while the
  state-only ratio model signs ~85% pooled but only ~40% of sign
  changes, and the imbalance-only model is never selected among 390
  monthly fits — pooled next-sign accuracy is dominated by
  mechanical persistence before any book state enters.
- **D4. The deterministic-calendar null** (39th, queued via
  deep-read 73, log ## 93, note
  `paper/research/library/2026-11-21_deterministic_time_varying_liquidity_deep_read.md`).
  Before a structure may enter any spec as support, it must be shown
  to survive a pre-declared deterministic-calendar null — a
  time-of-day surrogate built only from frozen constants (calendar
  position, e.g. a J-shaped intraday impact/liquidity profile as a
  pre-declared generic default), carrying zero book-state input; the
  Palmari–Lillo–Eisler paper proves the mechanism is real and needs
  literally no information: with permanent impact decaying linearly
  and temporary impact constant, the OPTIMAL liquidation of a long
  position begins by BUYING (Example 6, PDF pp. 16-17), and for T=1,
  a=5, η=0.25, b<−4.09 the excess cash is genuinely negative-cost
  proper price manipulation (PDF p. 17) with no self-excitation, no
  stochastic state, no news, nothing but the calendar.
- **D5. The queue-jump-diffusion generative-null pre-declaration**
  (42nd, queued via deep-read 81, log ## 107, note
  `paper/research/library/2026-11-21_order_book_dynamics_liquid_markets_deep_read.md`).
  Any spec claiming an anticipatory, depletion-side or
  queue-evacuation structure must pre-declare a moment-matched
  queue-jump-diffusion null (planar Brownian increments with drift
  from the pre-declared flow moments and correlation,
  re-initialized on boundary hits from a declared post-move depth
  distribution), with ALL null parameters — arrival rates, size
  moments, the correlation, the depth distribution — frozen BEFORE
  the data, and show the structure survives that null in the
  subsample where its information lives. The Cont–de Larrard
  diffusion-limit paper measures liquid-book queues as
  fluctuation-dominated at intraday scales (at 30 s the mean net
  queue change is roughly an order of magnitude below its standard
  deviation), so a depletion-side "anticipation" drift could be pure
  diffusion fluctuation with zero information and would survive any
  null weaker than the measured regime.

## Family E — queue-state conditioning and label discipline
(passive-flow features in the C1-L2 L2 arm)

- **E1. The queue-state conditioning disclosure rule** (23rd, queued
  via deep-read 26, log ## 34, note
  `paper/research/library/2026-11-18_passive_market_impact_point_process_deep_read.md`).
  A classical constant-kappa propagator gives the OPPOSITE sign for
  passive-metaorder impact (a passive buy pushes the price down); the
  sign is repaired only by conditioning on the book state, so any
  passive-flow feature carries a queue-state conditioning disclosure.
- **E2. The queue-state anticipation disclosure component** (25th,
  queued via deep-read 31, log ## 39, note
  `paper/research/library/2026-11-18_hyperliquid_sunshine_trading_deep_read.md`).
  The displayed book state is not exogenous scaffold but an elastic
  response to anticipated flow (imbalance moves at program start and

## Family H — dynamics identification for generative nulls

- **H1. The dynamics-identification rule for generative nulls** (29th,
  queued via deep-read 49, log ## 57, note

  deep-read 82, log ## 108, note

  Any spec attributing a price, spread or depletion-side association
  to an identified flow episode (a compression cluster, an OFI burst,
  a metaorder-like run) must pre-declare an attribution null in which
  the aggregate signed order-flow imbalance over the same window is
  conditioned out: the claimed episode-level association must survive
  in the subsample where the residual (episode-minus-aggregate) flow
  is statistically neutral, with the conditioning window, neutrality
  threshold and imbalance measure frozen BEFORE the data. The
  Donier–Bonart million-metaorder Bitcoin paper measures execution
  impact as almost perfectly the square root of the TOTAL market
  imbalance, not the metaorder's volume, and the market does not
  detect individual metaorders — an episode-attributed association
  could be pure common correlation and survives any null that does
  not condition it out.
