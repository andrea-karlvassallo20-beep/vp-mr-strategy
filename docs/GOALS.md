## The rotation rule

1. A due synthesis pass (front F9) outranks everything else.
2. Otherwise pick the highest-ranked ready front least recently
   advanced; ties break upward in rank.
3. The library deep-read queue (F1) is one front among the others,
   not the automatic default. Task type rotates by session;
   repetition needs a recorded reason.
4. "Ready" = entry criteria met and the front not blocked. A blocked
   front is advanced only by unblocking bookkeeping, never by
   violating its boundary.
5. Fail-safe: if this file is unreachable, unparseable, or internally
   inconsistent, run the fixed standing ritual unchanged and record
   the failure.

Per-front legend: ENTRY (when a session may claim it), FEEDS (what it
advances), BOUNDARY (its own kill line), STATUS (as of the edition
date). Statuses are refreshed only by synthesis passes; live pointers
are re-read from the programme log, never from memory.
