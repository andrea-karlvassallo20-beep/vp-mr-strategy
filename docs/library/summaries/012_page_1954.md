# 012 — On-line Detection of Abrupt Changes (Page, 1954)

**Venue:** Biometrika | **Category:** Change-point & shift
**Status:** Synthesized from LLM internal knowledge (Paywalled paper).

## Summary
Page introduces the cumulative sum (CUSUM) procedure for sequential
change detection: instead of a single-shot test, accumulate
log-likelihood increments and signal a change when the cumulative
sum of deviations from the "in-control" model drops below a
threshold. Asymptotically optimal for detecting a known shift
distribution with controlled false-alarm rate (ARL).

## The math that matters
$S_n = \sum_{i=1}^{n} \log \frac{f_1(x_i)}{f_0(x_i)}$, alarm when
$\max_{0 \le k \le n} (S_n - S_k) = \max_{k} \sum_{i=k+1}^{n}
\log \frac{f_1(x_i)}{f_0(x_i)} > h$ — the CUSUM recursion
$g_n = \max(0, g_{n-1}) + \log \frac{f_1(x_n)}{f_0(x_n)}$.

## Why it matters for the L2 project
L2 state changes (regime shifts in branching ratio, depth collapse)
are sequential detection problems: the data arrive, the gate must
decide "has the book changed?" online, with a controlled false-alarm
budget. CUSUM on the log-likelihood ratio of pre/post book-feature
distributions is the classical, near-optimal tool.
