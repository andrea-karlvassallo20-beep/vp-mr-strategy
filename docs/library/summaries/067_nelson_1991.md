**Venue:** Journal of Financial Economics | **Category:** Volatility & risk

## Summary
EGARCH: models the log of conditional variance as an ARMA in
standardized innovations, so variance is guaranteed positive
with no parameter constraints, and the asymmetry term captures
the leverage effect — negative returns raise future volatility
more than positive returns of the same size.

## The math that matters
$\log\sigma_t^2 = \omega + \beta\log\sigma_{t-1}^2 +
\alpha\left(|z_{t-1}| - E|z_{t-1}|\right) + \gamma z_{t-1}$ with
$z_t = \epsilon_t/\sigma_t$; $\gamma < 0$ produces leverage;
estimation by QML.

## Why it matters for the L2 project
Asymmetry is the known weakness of symmetric vol features
(realized vol, GARCH): the compression family measured
"quietness" symmetrically. If the L2 book state carries an
asymmetric toxicity measure (OFI direction matters), that is a
genuine structural difference from the OHLCV family — C8's micro
state is signed, the macro vol factor is not.
