# 049 — A Mathematical Framework for Modeling Order Book Dynamics (Cont, Xu et al., 2025)

**Venue:** SIAM Journal on Financial Mathematics | **Category:** Microstructure & order flow
**Status:** Synthesized from LLM internal knowledge (Paywalled paper; arXiv version may exist — script verifies).

## Summary
Formalizes the limit order book as a measure-valued Markov process:
the state is the empirical measure of resting orders, events
(limit/cancel/market) arrive with state-dependent intensities, and
price is a functional of the measure (best quotes). Establishes
well-posedness, propagation-of-chaos / fluid-limit results, and
the link between the microscopic event process and continuum
approximations (SPDE-type density models, cf. 059).

## The math that matters
Book state $X_t \in \mathcal{M}$ (finite measures on the price
grid); generator acting on cylinder functionals $F(X)$:
$\mathcal{A}F(X) = \sum_{\text{events } e} \lambda_e(X)\,
[F(X + \Delta_e) - F(X)]$; the mid-price functional
$m(X) = \tfrac{1}{2}(\sup\text{supp}(X^{bid}) +
\inf\text{supp}(X^{ask}))$.

## Why it matters for the L2 project
The rigorous backbone for treating L2 updates as a Markov event
stream: OFI terms are the linearization of $m(X)$'s response to
event increments, and Hawkes-type self-excitation is a specific
choice of state-dependent $\lambda_e$. C8's micro features are
functionals of this process.
