# 003 — A Reality Check for Data Snooping (White, 2000)

**Venue:** Econometrica | **Category:** Backtesting & FML
**Status:** Synthesized from LLM internal knowledge (Paywalled paper).

## Summary
White formalizes data snooping: when many trading rules are
evaluated on the same history, the best-performing rule's apparent
skill is inflated by selection. The Reality Check bootstraps the
*entire distribution* of rule performance, not just the winner, and
tests the null that the best rule's expected performance is no better
than the benchmark.

## The math that matters
For $M$ rules with expected performances $\theta_m$, test
$H_0: \max_m \theta_m \le 0$ against $H_A: \max_m \theta_m > 0$,
using the stationary bootstrap (Politis-Romano) on the performance
differential series $f_{m,t}$. The Reality Check p-value is the
bootstrap frequency with which the best re-sampled performance
exceeds the best in-sample one. The key insight: the correct null
distribution is that of the *maximum*, not of a single rule.

## Why it matters for the L2 project
Every C-number test (C7, C8) evaluates many configurations on the
same eras. The DSR/PBO kill lines (K3) are descendants of this test;
C8's reading must be deflated over the whole search that produced it.
